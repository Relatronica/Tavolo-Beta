# Registro delle decisioni

Un file per ogni scelta: **cosa** abbiamo deciso e **perché**. Serve a chi studia il progetto, a chi vuole criticarlo e a chi, fra un anno, si chiederà perché le cose stanno così.

## Come si legge

I file sono numerati nell'ordine in cui sono stati scritti. Ogni file ha uno **stato**:

- **Proposta**: scritta, non ancora discussa dal gruppo.
- **Adottata**: decisa.
- **Superata**: sostituita da una decisione più recente (si indica quale).

## Attenzione: queste prime voci sono ricostruite

Le prime sei voci (0001–0006) descrivono scelte già presenti nelle bozze 0.1. Sono state **ricostruite dai documenti**: il "contesto" e le "motivazioni" riportano solo ciò che i documenti dicono. Dove manca il motivo, c'è scritto **«Da completare dal gruppo»**. Non sono ancora state discusse formalmente, quindi lo stato è *Proposta*.

Copia [TEMPLATE.md](TEMPLATE.md), dagli il numero successivo e un nome breve (`0007-nome-breve.md`), poi aggiungi una riga all'indice qui sotto.
