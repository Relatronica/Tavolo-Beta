# Archivio degli esiti

Qui finiscono le [schede esito](../formato/scheda-esito.md) delle serate: cosa si è deciso, chi fa cosa, entro quando, com'è andata.

## Regole di questo archivio

1. **Solo esiti anonimizzati.** Niente cognomi, email, telefoni, indirizzi privati, foto di persone.
2. **Si usano nomi di battesimo o ruoli**, e solo se la persona è d'accordo.
3. **Tutti i presenti devono essere d'accordo a pubblicare.**
4. **Il luogo può essere generico** (es. "sala del circolo del quartiere", non l'indirizzo di una casa privata).
5. **Una scheda per serata**, in un file solo.

## Perché tanta cautela

Git conserva tutta la cronologia: un dato personale pubblicato e poi cancellato **resta recuperabile.** Chiedere di rimuoverlo da un repository pubblico è difficile, e per i dati personali di cittadini europei c'è il GDPR. Meglio non farli entrare.

Se per sbaglio un dato personale finisce qui, avvisaci subito: [CONTRIBUTING.md](../CONTRIBUTING.md).

## Come si nominano i file

```
AAAA-MM-GG-tema-citta.md
```

Esempio: `2026-12-02-lavoro-e-casa-quartiere-nord.md`. Nessun indirizzo, nessun nome di persona.

## Dopo due settimane

Si aggiunge in fondo alla scheda una riga con lo stato: **fatta**, **fatta in parte**, **non fatta, perché.** Servono a misurare quante decisioni si realizzano davvero.
