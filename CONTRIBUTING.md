# Come contribuire

Non serve sapere usare GitHub per partecipare a Tavolo Beta. Questo repository è per chi vuole approfondire. Se vuoi organizzare un tavolo, leggi la [guida](formato/organizza-un-tavolo.md).

## Hai fatto una serata?

Il contributo più utile è il tuo feedback. Dicci:

- cosa ha funzionato;
- cosa cambieresti nel formato;
- se vi rivedete.

Se usi GitHub, apri una issue con il modello "Feedback su una serata". Altrimenti scrivici all'indirizzo di contatto del sito: lo trascriviamo noi.

## Vuoi proporre una modifica al formato?

Apri una issue con il modello "Proposta di modifica al formato". Spiega:

1. cosa vorresti cambiare;
2. cosa hai osservato che ti fa pensare che serva;
3. se l'hai già provato, in quanti tavoli.

Il formato non cambia per una sola opinione: cambia dopo una prova in pochi tavoli e una lettura comune, con una nuova versione numerata.

## Vuoi correggere o migliorare un testo?

Va benissimo. Apri una pull request o una issue. Per i testi di teoria vale una regola: **si scrive quello che sappiamo, e si segna chiaramente quello che ipotizziamo.**

## Cosa non mettere mai nel repository

- Nomi, cognomi, email, telefoni di chi partecipa.
- Foto di persone.
- Qualsiasi dato che permetta di riconoscere una persona in un esito.

Anche se li cancelli dopo, restano nella cronologia. Se ti capita, avvisaci subito.

## Tono

Il disaccordo è benvenuto. Il processo alle intenzioni no.
